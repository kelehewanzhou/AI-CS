# 数据库权限配置说明

## 权限模型

系统采用最小权限原则，应用账号（`app_user`）仅拥有业务必需的权限：

### 1. 只读权限
- `courses`、`knowledge_nodes`、`knowledge_edges`：知识图谱核心数据
- `exercises`、`exercise_related_nodes`：练习题库
- `import_runs`：导入元数据

### 2. 读写权限
- `users`、`sessions`：认证会话管理（SELECT, INSERT, DELETE）
- `learning_events`：学习事件记录（SELECT, INSERT）
- `exercise_attempts`：答题记录（SELECT, INSERT）
- `qa_records`：问答记录（SELECT, INSERT）

### 3. 显式禁止
- ❌ DDL操作（CREATE, ALTER, DROP）
- ❌ DELETE业务数据（learning_events, exercise_attempts, qa_records）
- ❌ UPDATE已提交记录（幂等性保证）
- ❌ TRUNCATE任何表

## 账号职责分离

| 账号 | 职责 | 权限 |
|------|------|------|
| `postgres` | 超级用户 | 全部权限（仅运维使用） |
| `migrate_user` | 数据库迁移 | DDL权限、表结构管理 |
| `seed_importer` | 种子数据导入 | knowledge_*表的INSERT/UPDATE权限 |
| `app_user` | 应用运行时 | 见上述最小权限 |

## 部署步骤

### 首次部署

```bash
# 1. 使用超级用户创建应用账号
psql -U postgres -d kglearn -c "CREATE USER app_user WITH PASSWORD 'secure_password_from_env';"

# 2. 执行权限配置
psql -U postgres -d kglearn -f database/permissions.sql

# 3. 验证权限
psql -U postgres -d kglearn -c "
SELECT grantee, table_name, privilege_type 
FROM information_schema.table_privileges 
WHERE grantee = 'app_user' 
ORDER BY table_name, privilege_type;
"

# 4. 更新.env配置应用账号
# DATABASE_URL=postgresql+psycopg://app_user:secure_password@localhost:5432/kglearn
```

### Docker Compose环境

修改 `docker-compose.yml`：

```yaml
services:
  postgres:
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: ${DB_PASSWORD}
      POSTGRES_DB: kglearn
  
  migrate:
    environment:
      DATABASE_URL: postgresql+psycopg://postgres:${DB_PASSWORD}@postgres:5432/kglearn
    command: alembic upgrade head && psql -f /app/database/permissions.sql
  
  backend:
    environment:
      DATABASE_URL: postgresql+psycopg://app_user:${APP_DB_PASSWORD}@postgres:5432/kglearn
```

## 验证与审计

### 权限验证

```sql
-- 确认app_user无DDL权限
SET ROLE app_user;
CREATE TABLE test_table (id INT); -- 应失败

-- 确认app_user无法删除业务数据
DELETE FROM learning_events; -- 应失败

-- 确认app_user可以插入学习事件
INSERT INTO learning_events (user_id, event_type, resource_type, resource_id, created_at)
VALUES ('test-uuid', 'view_node', 'node', 'CO03', NOW()); -- 应成功
```

### 定期审计

```sql
-- 查看应用账号的实际执行操作（需要pg_stat_statements扩展）
SELECT query, calls, mean_exec_time, rows
FROM pg_stat_statements
WHERE usename = 'app_user'
ORDER BY calls DESC
LIMIT 20;
```

## 安全注意事项

1. **密码管理**：应用账号密码通过环境变量注入，不得硬编码
2. **连接池限制**：配置`pg_hba.conf`限制app_user的连接数
3. **审计日志**：启用PostgreSQL审计日志记录app_user的所有操作
4. **定期轮换**：每季度更换app_user密码
5. **网络隔离**：生产环境数据库不对外暴露，仅后端容器可访问

## 故障排查

### 权限不足错误

```
ERROR: permission denied for table courses
```

**原因**：app_user权限未正确配置

**解决**：使用postgres账号重新执行 `database/permissions.sql`

### 迁移失败

```
ERROR: must be owner of table knowledge_nodes
```

**原因**：使用app_user执行迁移

**解决**：迁移必须使用migrate_user或postgres账号
