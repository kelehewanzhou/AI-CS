# AT-05 习题与答题验收

## 测试场景

| # | 场景 | 预期结果 |
|---|---|---|
| 1 | 查询节点题目 | 返回学生视图，无 `answer_key` |
| 2 | 首次提交正确答案 | `201`，`is_evaluation=true` |
| 3 | 网络重试（相同 UUID + 答案） | `200`，返回原记录且不增行 |
| 4 | 相同 UUID 不同答案 | `409 CONFLICT` |
| 5 | 新 UUID 重做 | `201`，`is_evaluation=false` |
| 6 | 查询答题历史 | 只返回本人记录，按 `submitted_at DESC` 排序 |
| 7 | 用户 B 访问用户 A 的记录 | 不返回用户 A 的记录 |
| 8 | 判断题提交 boolean | 成功判分 |
| 9 | 判断题提交字符串或数字 | `422 VALIDATION_ERROR` |
| 10 | 同一用户同一题并发提交 10 次 | 全部创建，只有 1 条 `is_evaluation=true` |

## 自动化覆盖

`backend/tests/test_exercise.py` 覆盖题目学生视图、节点筛选、choice 判分、标准化答案、幂等重试、提交 ID 冲突、重做标记、本人历史、判断题严格 boolean、UUID 校验及并发首次评估。

## 启动与验证

```powershell
cd backend
python -m pytest -q
```

生产环境的提交事务使用 PostgreSQL `pg_advisory_xact_lock` 按用户和题目串行化，并由数据库的 `UNIQUE(user_id, client_submission_id)` 与首次评估局部唯一索引做最终约束。
