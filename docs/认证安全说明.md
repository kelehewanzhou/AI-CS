# 认证安全说明

## 密码存储

- 使用 Argon2id 算法。
- 使用 `argon2-cffi` 的 `PasswordHasher` 默认参数。
- 数据库只保存密码哈希，不保存明文密码。

## 会话管理

- 令牌使用 `secrets.token_urlsafe(32)` 生成。
- 数据库只保存令牌的 SHA-256 哈希。
- 会话有效期为 8 小时，不滑动续期。
- Cookie 使用 `HttpOnly`、`SameSite=Lax`；生产环境启用 `Secure`，开发环境关闭 `Secure`。
- 修改密码和退出登录会撤销会话；账号停用和会话过期会立即使 Cookie 失效。

## Origin 校验

- `/auth/login`、`/auth/logout`、`/auth/password` 的 POST 请求必须提供允许列表中的 `Origin`。
- 允许列表由 `.env` 中的 `ALLOWED_ORIGINS` 配置，按逗号分隔并进行精确匹配。
- `http://localhost:3000` 仅用于本地开发环境。

## 限流

由 Nginx 实现（任务 9），`/auth/login` 为 5 次/分钟。

## 已知限制

- 当前使用数据库会话表，未实现分布式会话存储。
- 当前未实现账号锁定机制。
- 当前仅强制密码长度，不强制复杂度规则。
- 当前不提供 SSO、第三方登录、邮件找回、图形验证码或用户自助注册。
