# AT-09 完整路径验收

## 学生路径

1. 访问 `/login/`，输入凭据
2. 首次登录跳转改密
3. 改密撤销全部会话，重新登录后跳转 `/graph/`
4. 选择课程 CO，查询
5. 点击节点 CO03
6. 查看节点详情、状态、关系
7. 点击“开始练习”
8. 提交 Q001 答案 A
9. 查看反馈“本次回答正确”
10. 访问 `/learning/`，查看事件和状态
11. 退出登录

## 教师路径

1. 登录教师账号
2. 访问 `/teacher/acceptance/`
3. 查看内容摘要
4. 查看证据分布
5. 退出

## 接口与静态页面检查

- [ ] 页面请求使用 `/api/v1` 前缀；Nginx将其代理到后端 `/auth`、`/graph`、`/nodes`、`/edges`、`/exercises` 和 `/learning` 路由
- [ ] 直接访问 `/node/?id=CO03`、`/edge/?id=E001`、`/exercise/?id=Q001` 后刷新仍可加载
- [ ] 清除Cookie访问受保护页面会回到 `/login/`
- [ ] 教师摘要由后端按角色授权，学生请求得到403并显示无权提示
- [ ] 习题提交失败或网络重试时复用同一个 `client_submission_id`，成功后才生成新的UUID
