# 导入错误定位示例

导入失败时，报告中的 `json_pointer` 从 `/items/0` 开始定位原始文件数组项。语法错误额外提供 `line` 和 `column`；结构、引用和业务错误不伪造行列号。

```json
{
  "file": "nodes.json",
  "item_index": 1,
  "json_pointer": "/items/1/title",
  "line": null,
  "column": null,
  "code": "ALIAS_CONFLICT",
  "message": "与节点CO03的标题或别名冲突"
}
```

常见错误代码包括：

- `JSON_SYNTAX_ERROR`：JSON 语法错误，提供行列号。
- `MISSING_FIELD`、`UNKNOWN_FIELD`：文件结构或字段不符合协议。
- `MISSING_REFERENCE`：边、节点或习题关联引用不在本批文件中。
- `ALIAS_CONFLICT`：节点标题或别名归一化后与其他节点重复。
- `DUPLICATE_RELATION`、`SELF_LOOP`：关系重复或自环。
- `IMMUTABLE_FIELD`、`RETIRED_ID`：数据库历史保护规则拒绝修改或复活。
