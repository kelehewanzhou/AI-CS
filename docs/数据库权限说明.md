# 数据库权限配置说明

## 权限模型

系统采用最小权限原则，应用账号（`app_user`）仅拥有业务必需的权限：

### 1. 只读权限
- `courses`、`knowledge_nodes`、`knowledge_edges`：知识图谱核心数据
- `exercises`、`exercise_related_nodes`：练习题库
- `import_runs`：导入元数据

### 2. 读写权限
- `users`、`sessions`：认证会话管理（SELECT, INSERT, DELETE）
- `learning_events`：学习事件记录（SELECT, INSERT）
- `exercise_attempts`：答题记录（SELECT, INSERT）
- `qa_records`：问答记录（SELECT, INSERT）

### 3. 显式禁止
- ❌ DDL操作（CREATE, ALTER, DROP）
- ❌ DELETE业务数据（learning_events, exercise_attempts, qa_records）
- ❌ UPDATE已提交记录（幂等性保证）
- ❌ TRUNCATE任何表

## 部署步骤

```bash
# 1. 使用超级用户创建应用账号
psql -U postgres -d kglearn -c "CREATE USER app_user WITH PASSWORD 'secure_password';"

# 2. 执行权限配置
psql -U postgres -d kglearn -f database/permissions.sql

# 3. 验证权限
psql -U postgres -d kglearn -c "
SELECT grantee, table_name, privilege_type 
FROM information_schema.table_privileges 
WHERE grantee = 'app_user' 
ORDER BY table_name, privilege_type;
"
```

## 安全注意事项

1. **密码管理**：应用账号密码通过环境变量注入，不得硬编码
2. **连接池限制**：配置pg_hba.conf限制app_user的连接数
3. **定期轮换**：每季度更换app_user密码
4. **网络隔离**：生产环境数据库不对外暴露，仅后端容器可访问
