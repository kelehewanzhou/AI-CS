## 命令

在项目根目录执行：

```powershell
python backend/cli/seed_import.py `
  --courses fixtures/courses.json `
  --nodes fixtures/nodes.json `
  --edges fixtures/edges.json `
  --exercises fixtures/exercises.json `
  --operator "admin@example.edu.cn"
```

导入报告会打印 `run_id`、状态、checksum、计数和最多100条错误；完整失败明细同时写入 `import_runs.error_summary`。
