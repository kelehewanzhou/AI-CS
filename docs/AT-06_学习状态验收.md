# AT-06 学习状态验收

本清单对应任务6和架构 §3.4、§3.6。测试数据使用仓库 `fixtures/` 结构夹具，夹具只用于自动化验证，不代表正式教学内容。

## 状态规则矩阵

每行使用独立用户。T/F 表示不同题目的首次提交，按时间从旧到新。`N` 是首次提交评估数，窗口 `W` 取最近 `min(5,N)` 条，`R` 按 `正确数×5 >= 窗口条数×4` 判断 80% 边界，`L` 是最新评估结果。

| 输入 | 预期 |
|---|---|
| 无事件、无答题 | 未学习，reason=`no_activity`，R=null |
| 仅 view_node | 学习中，reason=`viewed_or_started` |
| 仅 start_exercise | 学习中 |
| 无习题但已 view_node | 学习中，reason=`no_exercises`，can_evaluate_mastery=false |
| 仅 view_edge | 不改变节点状态，仍为未学习 |
| 未 view_node，T | 练习中，N=1 |
| T,T | 练习中，N=2，R=1 |
| T,T,T | 已掌握，N=3，R=1，L=true |
| T,F,T | 练习中，N=3，R=2/3 |
| T,T,T,F | 练习中，R=3/4，reason=`accuracy_below_threshold` |
| F,T,T,T,T | 已掌握，R=4/5=0.8 |
| T,T,T,T,F | 练习中，R=0.8，reason=`latest_evaluation_wrong` |
| F,F,T,T,T | 练习中，R=3/5=0.6 |
| F,T,T,T,T,T | 已掌握，只取最后5道，R=1 |
| 同题3次不同 UUID | 3条历史，1条评估，状态按唯一评估判定 |
| 同一 UUID 重试3次 | 1条历史，1条评估 |
| 一题关联 A/B，首次答 T | A/B 各计1条评估 |

## 接口和权限

- `POST /learning/events` 仅接受 `view_node/node`、`view_edge/edge`、`start_exercise/exercise` 配对；`submit_exercise` 必须返回 422。
- 资源必须存在且处于有效状态；未知节点、关系或题目返回 404。
- `GET /learning/events` 默认20条、最多100条，游标绑定当前用户、接口和事件过滤条件；篡改或跨用户使用返回 422。
- `GET /learning/summary` 返回 `seed_checksum`、`counts.courses/nodes/edges/exercises` 和 `edge_evidence_counts.verified/partial/pending`，不返回学生个人数据。
- 学生调用摘要返回 403；教师调用成功。
- `GET /nodes/{node_id}` 返回 `node`、有效 `exercise_count` 和当前用户 `learning` 三个组合字段。
