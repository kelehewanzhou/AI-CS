## 演练内容

使用临时独立PostgreSQL 17.11，执行真实迁移、导入与应用HTTP业务，包含用户、会话、答题、学习事件和问答快照。未连接任何现有项目或生产数据库。通过Git Bash执行仓库中与容器挂载相同的backup.sh和restore.sh，不用其他备份实现替代。

流程：pg_export_snapshot保留一致性快照 → pg_dump -Fc → pg_restore --list → 同快照全表计数和外键检查 → dump/counts SHA256 → 创建kglearn_restore_test → 单事务pg_restore → 全表计数diff及全部业务外键检查。计数包含alembic_version及11张P0业务表。

结果：恢复成功；exercise_attempts含真实通过接口提交的记录，重复提交没有重复记账；计数一致、外键无孤立记录。随后追加字节模拟备份篡改，restore非零退出并在替换演练库之前拒绝。精确行数和耗时采用机器记录，以免多轮验证后人工转抄过期。

最终含浏览器路径的演练备份/恢复/校验阶段4.837秒，恢复包含5名用户、8条会话、2条答题、5条学习事件、6条问答记录；所有表计数一致且外键检查通过。该结果只适用于小型夹具，不证明正式数据量RTO≤4小时或实际RPO≤24小时。
