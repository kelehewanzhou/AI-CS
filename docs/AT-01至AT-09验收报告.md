## 可复现命令

```powershell
python -m pytest backend/tests -q
cd web
.\node_modules\.bin\tsc.cmd --noEmit
.\node_modules\.bin\next.cmd build
cd ..
python scripts/verify_compose.py --compose-executable <官方docker-compose.exe路径>
python scripts/verify_native.py --pg-bin <PostgreSQL17的bin目录> --nginx-dir <官方Nginx目录> --browser
python scripts/version_manifest.py
```

verify_native在临时目录初始化全新集群、随机密码与端口，启动真实服务，结束停止其进程，不连接项目已有库。浏览器验证额外需要Playwright 1.56.0和Microsoft Edge；本次仅临时安装验证工具，没有加入生产依赖。Windows初始化可能因管理员降权令牌需要当前用户的临时目录显式ACL，脚本仅对其新建临时目录授予当前账户权限。

正式容器验收在具备Docker的目标机执行部署指南的init-env/check/deploy，首次与第二次维护发布都需验证；不能把原生运行或配置解析记作Docker镜像构建和Compose运行通过。
