# 任务0：工程基线与环境验证

**依赖**：无  
**预计工期**：3-5天  
**对应章节**：§5.1、§7.1、§4.6

## 本次只做什么

1. 创建项目目录结构（backend、web、database、docs）
2. 锁定Python依赖（pip-tools生成requirements.lock）
3. 锁定Node.js依赖（pnpm生成pnpm-lock.yaml）
4. 创建Docker Compose基础文件（postgres服务）
5. 编写.env.example模板
6. 准备§4.6的五节点结构测试夹具JSON文件

## 明确不做什么

- 不实现任何业务逻辑
- 不编写API接口
- 不创建数据库表
- 不实现前端页面
- 不配置Nginx
