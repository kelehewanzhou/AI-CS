# AI 跨课程知识图谱学习系统

面向学生与教师的跨课程知识图谱学习系统。当前项目按 MVP 范围逐步实现：浏览知识节点与关系、查看证据、完成练习并保存个人学习记录。

## 项目状态

本仓库用于工程实现与协作。架构设计文档目前为修订稿，尚未获得教学专家确认；正式知识节点、关系、证据及部分学习规则需要在进入相应实现阶段前确认。文档中的建议和测试夹具不得标记为正式已核验教学内容。

## 技术方向

- Web：React、Next.js、Cytoscape.js
- API：FastAPI
- 数据库：PostgreSQL
- 本地开发与部署：Docker Compose
- 首版问答：基于标题/别名匹配和固定模板，不依赖外部大模型

## 开发约定

- 默认开发分支：`dev`
- 架构、字段、接口与业务规则以 `docs/` 中的修订版设计文档为当前工程参考；遇到尚未确认的规则，先保留为待确认事项。
- 分阶段实现并验证；不要将测试夹具当作已确认的正式教学数据。
